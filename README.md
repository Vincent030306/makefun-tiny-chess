# tiny-chess-01

[![rank](https://make.fun/badge/tiny-chess-01/Vincent030306/tiny-chess-01/rank.svg)](https://make.fun/bounty/tiny-chess-01/leaderboard)

A chess engine in at most 4,096 bytes of Python, entered in make.fun's
"Build the strongest chess engine in 4 KB of Python" bounty.

## Run it

```sh
MAKEFUN_ENV_URL=<the env> python3 -P -s main.py
```
